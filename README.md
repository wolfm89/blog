<h2 align="center">What this is</h2>

Public Memory is my public notebook: notes, reflections and technical write-ups from
cloud architecture, data engineering, AI and the software I build along the way.

The site is intentionally simple: static HTML generated by Hugo, readable in light or
dark mode, and fast on a phone. The content lives in Markdown, so writing a post is just
adding a file and some text.

<h2 align="center">Stack</h2>

- **Hugo 0.169.0** with the extended binary
- **PaperMod** with a custom warm paper / forest theme
- **IBM Plex Sans** for reading and **Fraunces** for display headings
- **GitHub Actions** for validation and deployment
- **GitHub Pages** with a custom domain and HTTPS
- Built-in search, RSS, sitemap and taxonomies

<h2 align="center">Local development</h2>

```sh
hugo server
```

If Hugo is not installed globally, use the version pinned by the deployment workflow:

```sh
mise x hugo@0.169.0 -- hugo server
```

Then open <http://127.0.0.1:1313/>.

Build the production site:

```sh
mise x hugo@0.169.0 -- hugo build --gc --minify
```

<h2 align="center">Writing</h2>

Posts are page bundles under `content/posts/`:

```text
content/posts/24-12-bedrock-knowledge-base-terraform/
├── index.md
└── images/
    ├── rag-pre-processing.drawio.png
    └── rag-runtime-execution.drawio.png
```

Create a new post with:

```sh
hugo new content posts/my-new-post/index.md
```

Keep images next to the post in its `images/` directory. The front matter controls the
title, description, tags, table of contents and share buttons.

<h2 align="center">Theme</h2>

The custom theme lives in `assets/css/extended/`:

| File | Purpose |
| --- | --- |
| `theme-vars.css` | Palette, fonts, radii, shadows and light/dark tokens |
| `forest.css` | Header, profile, cards, post typography, tags, search, footer and 404 |

Fonts are loaded in `layouts/_partials/extend_head.html`. The theme supports light,
dark and automatic mode, and follows `prefers-reduced-motion`.

The palette is warm paper (`#efece0`), card surface (`#fffdf8`), forest (`#3f6b45`),
sage (`#6d9e51`) and wood (`#a9805a`). In dark mode the page goes to a deep forest night
(`#10150f`).

The faint wood-grain background lines are the two SVGs in
`static/images/wood-grain-{light,dark}.svg`. Their strokes are intentionally 5–11% opaque;
CSS applies the final 0.4 (light) / 0.16 (dark) layer opacity.

<h2 align="center">Deployment</h2>

- Pull requests run the Hugo build as a validation step.
- Pushes to `main` build and deploy through `.github/workflows/hugo.yaml`.
- The site is served at <https://blog.wolfgangmoser.eu/> with HTTPS.
- The search page is intentionally `noindex`; the sitemap excludes it.

<h2 align="center">Structure</h2>

| Path | Purpose |
| --- | --- |
| `content/` | Posts, About and section pages |
| `layouts/` | Homepage recent posts, single-page and 404 overrides |
| `assets/` | Theme CSS and source images |
| `static/` | Favicons, social image and background textures |
| `themes/PaperMod/` | PaperMod theme |
